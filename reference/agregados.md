# API servicodados.ibge ... Todos agregados disponíveis

Para utilização inicial, base com todos agregados disponíveis

## Usage

``` r
data(agregados)
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 6
rows and 3 columns.

## Source

[IBGE API](https://servicodados.ibge.gov.br/api/docs/agregados?versao=3)

## Examples

``` r
data(agregados)
```
